# cards-side-nav

Custom **cards** block. 

## Authoring (Document Authoring)

Model: `standalone`

One row per section page; the cell holds the page link, optionally followed by a bulleted list of sub-page links. The item matching the current URL (exact, or the URL ending with the link path) is highlighted; sub-page lists are collapsible via a toggle button and expanded for the active branch only.

No variations.
