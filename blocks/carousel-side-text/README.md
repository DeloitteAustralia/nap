# carousel-side-text

Custom **carousel** block. Purpose: Homepage promo carousel: one row per slide, a linked promo image in cell 1 (headline/CTA baked into the image, so the alt text must carry them) and a caption text panel in cell 2. Prev/next, dot indicators and a pause/play button appear with two or more slides; a single slide renders as a static image and panel. Rotates every 6s unless the user prefers reduced motion; pauses on hover/focus.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide, two cells: (1) image, linked to the slide target, with alt text carrying the headline baked into the image; (2) text panel: optional heading, paragraph(s), optional CTA link. A single row renders a static slide with no controls.
