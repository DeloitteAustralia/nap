# cards-news

Custom **cards** block. Purpose: News list without images (e.g. the What's New panel): one row per item with a title heading (h4), a bold date paragraph, a summary paragraph and a read more link paragraph. The panel heading itself is default content above the block.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per news item, one cell: title heading (h4), date as a bold paragraph (e.g. **05 August 2026**), summary paragraph, and a "read more" link in its own paragraph.

## Supported variations

No variations.
