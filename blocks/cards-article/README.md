# cards-article

Custom **cards** block. Purpose: Grid of article teaser cards: one row per card, image in cell 1 and heading (h3), description and a Read more link (own paragraph) in cell 2. Stacked below 768px, 2-up from 768px, 3-up from 992px (matches the source col-sm-6 / col-lg-3 grid).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card, two cells: (1) image; (2) heading (h3), description paragraph(s), and a "Read more" link in its own paragraph.
