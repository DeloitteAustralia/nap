# accordion-faq

Custom **accordion** block. 

## Authoring (Document Authoring)

Model: `standalone`

Block table: one row per FAQ item. Cell 1 is the question (rendered as the clickable summary); cell 2 is the answer (paragraphs, lists, links). Rows without a question are dropped; a missing answer renders an empty panel. All items start collapsed; opening one closes the others (shared `name` on the `<details>` elements).
